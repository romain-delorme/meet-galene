# How are Galene-related files organized ?

## Frontend

All Galène frontend elements can be found in `src/frontend/src/features/rooms/galene/`. This directory is comprised of the following elements:
- React.js components, found in `components/`, see `docs/galene/components.md` for more details
- React.js hooks, found in `hooks/`, see `docs/galene/hooks.md` for more details
- Galène protocol and related functions, found in `protocol/`, see `https://github.com/jech/galene/blob/master/galene-protocol.md` for more details
- A GaleneContext.tsx file which defines the structure of Galène objects, see `docs/galene/context.md` for more details
